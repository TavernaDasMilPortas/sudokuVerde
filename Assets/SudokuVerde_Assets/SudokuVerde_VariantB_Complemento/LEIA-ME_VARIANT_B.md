# Sudoku Verde — complemento Variação B

Extraia diretamente dentro de SudokuVerde_Assets. Os diretórios PNG, SVG e Referencias serão mesclados sem sobrescrever os arquivos da Variação A.

Use PNG para importação simples ou SVG se houver suporte na Unity. Textos dos seletores (ON/OFF, Versão A/B), títulos e contadores devem ser Labels do UI Toolkit. Os diagramas são PNG com fundo creme original. A marcação X grande e overlay são aproximações; demais componentes vetoriais foram reconstruídos dos caminhos do AI. Reutilize ilustração, plantas, lâmpada, células, fundo degradê, grama, brilhos e badge da Variação A. Não há fonte inclusa.
